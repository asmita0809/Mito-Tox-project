WHAT THIS MEANS, AND WHAT IT DOES NOT

The difference is attributable to XGBoost, not to this code. The
selection stage consumes only stored out-of-fold predictions and
scikit-learn metric functions, and it reproduces exactly in both
environments. The stage that differs is the one that fits an
XGBClassifier, and the two environments differ by an XGBoost minor
version (3.2.0 vs 3.4.1). Gradient-boosted tree construction is not
guaranteed to be bit-stable across versions: histogram binning,
tie-breaking among equally-scoring splits and floating-point
accumulation order can all change.

So the exact digits in this README are reproducible WITH THE PINS, and
not otherwise. requirements.txt is a requirement, not a convenience.

The scientific conclusion is more robust than the digits. The -0.0266
shift in PR-AUC is small relative to the bootstrap 95% confidence
interval on that same number, [0.638, 0.775], a width of 0.137. Both
environments put the model far above the 0.148 no-skill baseline set by
class prevalence, both reproduce the ranking of the 108 candidate
configurations identically, and both support the same statement: the
model carries real signal on an analogue-disjoint test set, with
sensitivity around 0.6 at high specificity.

What would NOT be legitimate is quoting 0.709 as if it were a property
of the method rather than of the method plus this exact dependency set.
The number is reported here with its environment attached.


A PREVIOUS CLAIM IN THIS README WAS WRONG

An earlier version of this README stated that every result had been
regenerated on a second machine with different Python and scikit-learn
versions and reproduced bit-identically. That claim did not survive
being checked. It is possible that the two environments compared at the
time shared an XGBoost version, which would make the original
observation correct but the generalisation unwarranted; the records that
would settle it no longer exist. Either way the sentence asserted more
than the evidence supported, and it has been replaced by this file and
by the measured figures above.
